# Changelog

## 0.1.2

- A new tab opened from the title bar is ready for typing immediately, and fast command output redraws more smoothly.
- SSH sessions can detect when the underlying process exits even if the usual session notification is unavailable.
- The Flatpak runs local commands inside its sandbox and supports remote sessions over SSH.

## 0.1.0

- Run local shells and SSH sessions in a native terminal.
- Public enzUI Alpha 0.1 with native themes and system/theme fonts.

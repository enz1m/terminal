# Contributing to Terminal

Use shared enzUI widgets, theme tokens and native services. Keep blocking work
off the UI thread and preserve bounded input, cancellation, stale-result guards,
credential privacy and user file integrity. Keep tests for app-owned boundaries
and durable user workflows; avoid source-spelling and cosmetic widget tests.

Run the formatting, test and Clippy commands in the README. Check affected native
workflows in both appearances and at wide/narrow window sizes. Use disposable
state and synthetic data. Keep private fixtures, theme presets and review logs
under ignored AGENTS/; curated images belong in docs/screenshots.

Do not send real messages, install applications, change services or operate on
real disks merely to test the interface. Preserve licenses and attribution.
